# RokuLab agent guide

- Read `AGENTS.md`, `README.md`, and every file in `project-memory/` before changing the project.
- Update project memory after each completed milestone.
- Never call a feature complete without a test or other reproducible evidence.
- Preserve prior decisions; mark replaced decisions as superseded with a reason.
- Keep documents concise and never store secrets.
- Keep sensitive/local state ignored and publish each new version as a GitHub release when a remote and credentials are available.
