# Roadmap

- 0.1 alpha: open project, manifest/tree, basic SceneGraph, virtual display/remote, console, reload.
- 0.2: stronger BrightScript runtime, properties, observers, focus, inspector.
  - In progress: linear sub calls, node aliases, observer/property inspection, and geometric focus are implemented; observer dispatch and control flow remain.
- 0.3: Roku API layer, registry, device profiles, network inspector.
- 0.4: media player, screenshots, test runner, headless mode.
- 0.5: debugger, performance tools, physical-device ECP/deploy.
- 1.0: documented compatibility threshold and stable plugin/API contracts.
